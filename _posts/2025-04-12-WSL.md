# 使用 **Xshell** 连接 WSL 的 Ubuntu

### **1. 确保 WSL 的 Ubuntu 已安装 SSH 服务**

在 WSL 的 Ubuntu 终端中运行：


```shell
sudo apt update && sudo apt install openssh-server -y
```

------

### **2. 修改 SSH 配置（允许密码登录）**

编辑 SSH 配置文件：

bash

``
sudo nano /etc/ssh/sshd_config
``

修改以下参数：

```shell
Port 22                  # 确保端口是 22（或自定义其他端口）
ListenAddress 0.0.0.0    # 允许所有 IP 连接
PasswordAuthentication yes  # 允许密码登录
PermitRootLogin yes      # 允许 root 登录（可选，建议用普通用户）
```

保存后退出（`Ctrl+X` → `Y` → `Enter`）。

------

### **3. 启动 SSH 服务**

bash

```shell
sudo service ssh start
```

如果提示 `Failed to start sshd.service`，可以尝试：

bash

```shell
sudo /etc/init.d/ssh start
```

设置开机自启（可选）：

bash

```shell
sudo systemctl enable ssh
```

------

### **4. 检查 WSL 的 IP 地址**

在 WSL 终端运行：

bash

```shell
ip addr show eth0 | grep "inet\b" | awk '{print $2}' | cut -d/ -f1
```

记录输出的 IP 地址（如 `172.xx.xx.xx`）。

------

### **5. 在 Xshell 中连接 WSL**

1. 打开 **Xshell**，点击 **新建会话**。
2. 填写连接信息：
   - **名称**：WSL Ubuntu
   - **协议**：SSH
   - **主机**：WSL 的 IP 地址（如 `172.xx.xx.xx`）
   - **端口**：22
   - **用户名**：你的 WSL 用户名
3. 点击 **连接**，输入密码即可登录。

------

### **6. 常见问题解决**

#### **Q1: 连接超时或拒绝连接**

- 检查 WSL 的 SSH 服务是否运行：

  bash

  ```shell
  sudo service ssh status
  ```

- 确保 Windows 防火墙允许 WSL 的 SSH 端口（如 22）。

#### **Q2: WSL 的 IP 地址每次重启会变**

- 解决方案：
  1. 在 Windows 中通过 `wsl -l -v` 查看 WSL 名称（如 `Ubuntu-20.04`）。
  2. 使用 `wsl -d Ubuntu-20.04` 启动 WSL，再运行 `ip addr` 查看 IP。

#### **Q3: 如何固定 WSL 的 IP 地址？**

WSL 2 默认使用 NAT 网络，IP 会变。可以：

1. 使用 **Windows 的 `localhost`** 连接（需端口转发，见下文）。
2. 或通过 **Hyper-V 虚拟交换机** 设置静态 IP（较复杂）。

------

### **7. 替代方案（推荐）：通过 localhost 连接**

由于 WSL 2 的 IP 会变，更稳定的方法是：

1. 在 WSL 中运行：

   bash

   ```shell
   sudo nano /etc/ssh/sshd_config
   ```

   修改 `ListenAddress 0.0.0.0` → `ListenAddress 127.0.0.1`（仅本地访问）。

2. 在 Windows PowerShell 中设置端口转发：

   powershell

   ```shell
   netsh interface portproxy add v4tov4 listenport=2222 listenaddress=0.0.0.0 connectport=22 connectaddress=127.0.0.1
   ```

3. 在 Xshell 中连接：

   - **主机**：`localhost` 或 `127.0.0.1`
   - **端口**：2222

------

### **总结**

- **直接连接**（适合临时使用）：用 `ip addr` 查 WSL IP，Xshell 连接。
- **稳定连接**（推荐）：配置 `localhost:2222` 端口转发，避免 IP 变化问题。

这样就能在 Xshell 中流畅使用 WSL 的 Ubuntu 了！🚀
